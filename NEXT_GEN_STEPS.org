** DONE 0.5 Invoke + API — ~grease.ios.invoke~ + ~grease.ios.api~

Implement the dispatch core.  With mock bridge, verify the full pipeline.

Algorithm (from §4.6):
1. Resolve class from ~repl/class-name-of~
2. Look up method spec (keyword → clj-name index, string → raw selector)
3. Parse ~:encoding~ → return-type + per-arg encoding chars
4. Walk args: route patterns → ~types/coerce-in~
5. Build flat ~[type value ...]~ list for ~objc-rt/msg-send~
6. Wrap in ~repl/on-main~ if ~:main-thread? true~
7. Apply ~types/coerce-out~ or enum decode to result
8. Return

*** DONE 1.2.1 Audit engine namespaces for SCI compatibility

Read all seven engine source files.  Findings below.  Only one namespace
has blocking issues; everything else is safe.

**** ~grease.ios.types~ — BLOCK (two ~requiring-resolve~ calls)

1. ~resolve-coercer~ (line 44) — called during ~init!~ to resolve coercer
   symbols (e.g. ~'grease.ios.foundation/->nsstring~).
   ~requiring-resolve~ goes through the JVM classloader; in frozen SCI,
   it is unreliable.  Fix: replace with ~resolve~, which is sufficient
   because foundation is already eval'd into SCI before types loads.

2. Inline in ~coerce-in~ (line 105): ~(requiring-resolve 'grease.ios.foundation/null-ptr)~.
   Called on *every* nil-pointer coercion.  Even if the frozen-image issue
   were absent this would be slow.  Fix: cache ~null-ptr~ as a ~delay~ or
   resolve it once during ~init!~.

**** ~grease.ios.naming~ — SAFE

~defmulti~ / ~defmethod~, ~re-pattern~, ~clojure.java.io/resource~,
~clojure.edn~, ~clojure.string~ — all available in SCI.  No issues.

**** ~grease.ios.spec~ — SAFE (verify ~slurp~ on URL at runtime)

~io/resource~ returns a ~java.net.URL~; ~slurp~ on a URL is standard
Clojure and works in SCI.  Resources are bundled in the native image
via GraalVM ~--initialize-at-build-time~, so ~io/resource~ resolves at
runtime.  Low risk; worth a quick sanity check in the REPL after 1.2.3.

**** ~grease.ios.registry~ — SAFE

~defonce~, ~clojure.string/lower-case~, atoms, maps.  No issues.

**** ~grease.ios.invoke~ — SAFE

Plain encoding-map lookups, ~mapcat~, calls ~objc/msg-send~,
~patterns/wrap-arg~, ~types/coerce-in/out~.  No ~requiring-resolve~.
No issues.

**** ~grease.ios.patterns~ — BLOCK (Math/abs in frozen native image)

~defmulti~ / ~defmethod~ — SCI supports both.  ~defonce~ — fine.
~(Math/abs (int (hash ...)))~ — FAILS in frozen native image: ~java.lang.Math~
is not in ~conf/reflectionconfig-arm64-ios.json~.  SCI cannot call it via
reflection.  Fix: replace with ~(bit-and (hash ...) 0x7fffffff)~.

**** ~grease.ios.api~ — SAFE (indirect dependency on types fix)

~defrecord ObjcObject~, ~instance?~, no direct ~requiring-resolve~.
Calls ~types/init!~, so it inherits the block from types — but once
1.2.2 is fixed, api is clean.
