data-driven engine.  Drop an EDN file in ~resources/grease/api-specs/~; the

** DONE 0.5 Invoke + API — ~grease.ios.invoke~ + ~grease.ios.api~

Implement the dispatch core.  With mock bridge, verify the full pipeline.

Algorithm (from §4.6):
1. Resolve class from ~repl/class-name-of~
2. Look up method spec (keyword → clj-name index, string → raw selector)
3. Parse ~:encoding~ → return-type + per-arg encoding chars
4. Walk args: route patterns → ~types/coerce-in~
5. Build flat ~[type value ...]~ list for ~objc-rt/msg-send~
6. Wrap in ~repl/on-main~ if ~:main-thread? true~
7. Apply ~types/coerce-out~ or enum decode to result
8. Return

#+begin_src clojure
;; grease/ios/api.clj — user-facing API
(ios/make   :av-player {:url "https://..."})  ; -> instance pointer
(ios/call   player :play)                     ; -> nil
(ios/get-prop player :status)                 ; -> :ready-to-play
(ios/set-prop! player :volume 0.5)
(ios/watch  player :status (fn [old new] ...)) ; -> handle
(ios/unwatch handle)
(ios/enum   :av-player-status :ready-to-play)  ; -> 1
(ios/load!)   ; load all specs
(ios/reload!) ; reload from disk
#+end_src

Gate (oracle test): for every function in ~grease.ios.foundation~, assert

** DONE 0.7 Patterns — KVO + completion handlers
