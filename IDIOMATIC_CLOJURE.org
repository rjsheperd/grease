#+TITLE: Grease Idiom Layer
#+AUTHOR: RJ Sheperd
#+STARTUP: overview

* Preamble

The low-level engine gives you ~(ios/call obj :method args)~. Faithful and correct, but
verbose for anything beyond exploratory REPL work. This layer maps every recurring iOS
pattern to the Clojure idiom that already solves the same problem.

| iOS pattern                            | Clojure idiom                  | Why                                                         |
|----------------------------------------+--------------------------------+-------------------------------------------------------------|
| Delegate + mutable state               | ~agent~                        | Serialised async state from off-thread callbacks            |
| KVO observation                        | ~add-watch~ on a synthetic ref | Same contract: notify on state change                       |
| View tree built with ~addSubview:~     | Hiccup vectors                 | Declarative tree → imperative mutations (Reagent's pattern) |
| Completion handler ~(result, error)~   | ~promise~ + ~deref~ + timeout  | One-shot async result delivery                              |
| NSNotificationCenter                   | Multimethod event bus          | Pub/sub with keyword dispatch keys                          |
| Auto Layout constraints                | Constraint EDN                 | Relationships between named views as data                   |
| UIView animation blocks                | Threading macro                | Record-then-execute, composable sequences                   |
| ~@autoreleasepool { }~                 | ~with-open~-shaped macro       | Scoped resource cleanup                                     |
| Target/action for controls             | ~:on-tap~ keyword in hiccup    | Event handler as data                                       |

Every layer exposes the one below. Users who dislike hiccup can call ~(ios/call ...)~;
users who dislike ~defdelegate~ can call ~(objc-rt/defclass ...)~. No escape hatches
needed because the abstractions do not hide their foundation.

** SCI compatibility constraints (apply to every phase)

- No nested backticks. Compute inner forms with ~mapv~ outside the outer backtick.
- All symbols inside syntax-quote must be fully qualified.
- No ~core.async~. Use ~promise~ and ~add-watch~.
- No ~clojure.spec.alpha~ runtime calls.
- No ~requiring-resolve~ in hot paths; cache results in atoms.
- Custom types (~IDeref~, ~IRef~) must work under SCI — test early; fall back to maps +
  functions if ~deftype~-with-protocol is unsupported.

* Phase 0: Foundations
** DONE 0.1 Retention Registry
:PROPERTIES:
:file: src/grease/ios/retain.clj
:loc: ~60
:END:

Every existing wrapper manages ARC retention with ad-hoc atoms. The idiom layer creates
ObjC objects prolifically; a single centralised table scales better.

- ~(retain! key ptr kind)~ — store ptr under key; return key
- ~(release! key)~ — remove from table, return ptr (caller sends final messages first)
- ~(release-kind! kind)~ — bulk teardown (e.g. all ~:delegate~ entries for one screen)
- ~(retained key)~ — lookup, nil if absent
- ~(retained-keys)~ / ~(retained-count)~ — REPL introspection
- ~(reset-all!)~ — emergency escape hatch

Tests: retain/release round-trip; ~release-kind!~ selectivity; double-release is no-op.

** DONE 1.1 ~defdelegate~ macro

Input shape:
#+begin_src clojure
(defdelegate LocationDelegate "CLLocationManagerDelegate"
  {:state   {:location nil :error nil}
   :methods {[:location-manager _ :did-update-locations locs]
             (fn [state _mgr locs]
               (assoc state :location (first-location locs)))}})
#+end_src

- Method descriptor ~[:location-manager _ :did-update-locations locs]~ → selector
  ~"locationManager:didUpdateLocations:"~
- State-transition fn signature: ~(fn [current-state & coerced-objc-args] -> new-state)~
- Expansion creates a factory function ~def~'d as ~LocationDelegate~ in the calling ns

** DONE 1.2 Selector reconstruction

~[:location-manager _ :did-update-locations _]~ → ~"locationManager:didUpdateLocations:"~

Pure function; testable on JVM. Build a translation table from all selectors used in
existing wrappers and assert each reconstructs correctly.

** DONE 1.3 Type-encoding

v1: require explicit ~:encoding "v@:@@"~ in the method descriptor.
v2 (post-engine): look up from framework spec EDN.

** DONE 1.4 Macro expansion

- Factory returns a Clojure ~agent~ wrapping ~:state~
- Agent metadata holds ~{::objc-ptr <ptr> ::protocol <name>}~
- Each ObjC method IMP calls ~(send agent transition-fn & coerced-args)~
- Delegate pointer retained in registry (Phase 0.1)

** DONE 1.5 ~objc-ptr~ / ~release-delegate!~

- ~(objc-ptr agent)~ — extract ObjC pointer from agent metadata
- ~(release-delegate! agent)~ — remove from retention registry

** DONE 1.6 Error handling

Wrap every transition in ~try/catch~, log the error, return previous state unchanged
(store last error under ~::last-error~ in state). Avoids silent callback drops.

** DONE 1.7 Protocol conformance

After ~defclass!~, call ~(objc-rt/add-protocol! cls protocol-name)~ so
~conformsToProtocol:~ checks pass.

** DONE 1.8 Tests

Oracle test: rewrite ~bluetooth.clj~ delegate with ~defdelegate~; assert ~@bt-delegate~
produces identical state transitions.

* Phase 2: KVO as ~add-watch~
:PROPERTIES:
:file: src/grease/ios/kvo.clj
:depends: Phase 0.1
:loc: ~180 impl + ~100 tests
:END:

~addObserver:forKeyPath:options:context:~ / ~removeObserver:forKeyPath:~ are pure
~msg-send~ calls — no struct shims needed.

** DONE 2.1 Internal observer class

~defclass!~ a ~GreaseKVOObserver~ once at module load with method
~observeValueForKeyPath:ofObject:change:context:~ (~"v@:@@@@"~). Its IMP dispatches
to a Clojure dispatch table atom ~{context-id → callback-fn}~.

Context IDs: a global counter atom (simplest; no pointer fragility).

** DONE 2.2 ~(observe obj key-path)~

Returns a value implementing ~IDeref~ and ~IRef~ (~add-watch~ / ~remove-watch~).

On creation:
1. Allocate unique context ID
2. Register ~context-id → update-atom~ in dispatch table
3. ~addObserver:forKeyPath:options:context:~ (options = ~3~: new + old)
4. Retain in registry

~deref~ returns current value. ~add-watch~ / ~remove-watch~ delegate to the internal atom.

** DONE 2.3 ~(release! observable)~

- ~removeObserver:forKeyPath:~ on original object
- Remove from dispatch table and retention registry
- Notify all watches with ~nil~ (signals observation ended)

** DONE 2.4 ~(reaction expr-fn & observables)~

Derived ref: re-evaluates ~expr-fn~ whenever any input changes; only fires watches when
the *derived* value changes.

** DONE 2.5 Tests

JVM: simulate KVO notification via direct dispatch-table call; verify ~deref~ and
~add-watch~ fire. Integration: observe UIView ~alpha~ property, change it, verify
callback fires (~^:integration~).

** DONE 3.3 ~(on notification-key callback-fn)~

~UIView animateWithDuration:animations:completion:~ and the spring variant take block

** DONE 5.1 ~(animate opts body-fn)~

    (set-alpha! view 0.0)

** DONE 5.3 ~(chain & [opts fn] ...)~  [named chain to avoid clojure.core/sequence clash]

  :state   {:items [] :filter :all}
