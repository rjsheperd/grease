* Phase 2 — ObjC Blocks (Completion Handlers)

ObjC blocks are the single most important missing piece for modern iOS APIs.
URLSession, UIView animations, HealthKit authorization, and most async
callbacks use blocks, not delegate protocols.

** TODO 2.1 Write C shim layer in Xcode project

#+begin_src objc

typedef void (*GreaseDataFn)(void *ctx, id data, id response, id error);

void (^grease_make_void_block(GreaseVoidFn fn, void *ctx))(void);

** TODO 5.2 Better error surfacing from ~dispatch-main-async~

Wrap main-thread dispatches so exceptions propagate back to nREPL output:

#+begin_src clojure
(defmacro on-main [& body]
  `(let [result# (promise)]
     (dispatch-main-async
       (fn []
         (try
           (deliver result# {:ok (do ~@body)})
           (catch Exception e#
             (deliver result# {:err (Throwable->map e#)})))))
