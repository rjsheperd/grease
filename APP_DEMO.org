* Goal

A live demo app controlled entirely from the Clojure nREPL:

- Two-tab bottom tab bar (~UITabBarController~)
- *Tab 1 — Map*: full-screen ~MKMapView~, blue user-location dot, map
  auto-centers on first GPS fix, re-centers on each update
- *Tab 2 — Info*: ~UILabel~ stack showing live lat/lon/accuracy/timestamp,
  updated by an atom watch every time CLLocation changes

Zero ~Bridge.m~ changes after Phase 0. Zero ~build-bb-o~ rebuilds after
Phase 0. All logic lives in Clojure, loaded from the nREPL.

** DONE 0.3 Add C shim ~grease_set_map_region~

~setRegion:animated:~ takes an ~MKCoordinateRegion~ struct by value (32 bytes
= 2× HFA of 16 bytes each).  Cannot be called via a generic ~msg-send~.
Add a scalar-arg shim to ~xcode/MobileTest/csource/Bridge.m~ and ~Bridge.h~:

#+begin_src objc
// Bridge.h
void grease_set_map_region(void *mapView,
                           double center_lat, double center_lng,
                           double span_lat_delta, double span_lng_delta,
                           BOOL animated);

// Bridge.m
#import <MapKit/MapKit.h>

void grease_set_map_region(void *mapView,
                           double center_lat, double center_lng,
                           double span_lat_delta, double span_lng_delta,
                           BOOL animated) {
    MKMapView *mv = (__bridge MKMapView *)mapView;
    MKCoordinateRegion r =
        MKCoordinateRegionMake(
            CLLocationCoordinate2DMake(center_lat, center_lng),
            MKCoordinateSpanMake(span_lat_delta, span_lng_delta));
    [mv setRegion:r animated:animated];
}
#+end_src

Expose in Clojure as:

(defn set-map-region!
  "Centers mapView on [lat lng] with the given degree span."
  [map-view lat lng lat-delta lng-delta animated?]

            :pointer map-view
            :float64 lat  :float64 lng
            :float64 lat-delta :float64 lng-delta
            :int8    (if animated? 1 0)))

** DONE 3.1 Write ~dev/demo_app/location.clj~

#+begin_src clojure
(ns demo-app.location
  (:require [grease.ios.api        :as ios]
            [grease.ios.objc       :as objc-rt]
            [grease.ios.foundation :as f]
            [grease.ios.repl       :refer [on-main]]))

(defonce location     (atom nil))
(defonce location-mgr (atom {}))

(defn- on-location-update
  "Called by the delegate on each GPS fix.  Updates @location atom."
  [_mgr locs]
  (let [arr    (f/nsarray->vec locs)
        latest (last arr)]
    (reset! location latest)))

(defn start!
  "Initializes CLLocationManager, wires delegate, requests authorization, starts updates."
  []
  (on-main
    (let [mgr (ios/make :location-manager)]
      (ios/call mgr :request-when-in-use-authorization)
      (ios/call mgr :set-delegate
        {:location-manager-did-update-locations on-location-update
         :location-manager-did-fail-with-error
         (fn [_mgr err]
           (println "CLLocation error:"
                    (f/nsstring->str
                     (objc-rt/msg-send :pointer err "localizedDescription"))))})
      (ios/call mgr :start-updating-location)
      (reset! location-mgr {:mgr mgr}))))

(defn stop! []
  (when-let [mgr (:mgr @location-mgr)]
    (on-main (ios/call mgr :stop-updating-location))))
#+end_src

** DONE 4.6 Phase 4 Architecture Review — Final

Findings (code analysis; on-device confirmation deferred to 4.5):

*** 4.6.1 Idiomatic Clojure audit

- No ~def~ inside function bodies.  All mutable state is in top-level ~defonce~ atoms.
- All side-effectful functions end in ~!~ (~start!~, ~stop!~, ~clear!~, ~install!~,
  ~update!~, ~reset-state!~, ~install-tab-bar!~, ~install-map-view!~, ~restart!~).
  Pure helpers (~latitude~, ~longitude~, ~accuracy~, ~screen-width~, ~screen-height~)
  return nouns.
- No function exceeds 20 lines after the namespace split.
- One bare ~println~ remains in the CLLocation error callback in
  ~demo-app.location/start!~.  Acceptable for a demo; a production version
  would append to a ~(defonce log (atom []))~.
- ~dev/~ files are exempt from docstring requirements; all public fns have
  leading comments explaining purpose.

*** 4.6.2 Engine API coverage

All ~objc-rt/msg-send~ calls in the demo use selectors that are one-off
UIKit construction calls.  The engine API (~ios/call~) is used for
CLLocationManager calls (~:request-when-in-use-authorization~,
~:start-updating-location~, ~setDelegate:~).  The split is intentional
and correct (see 0.6 item 2).  No raw ~msg-send~ appears more than once
for the same selector.

*** 4.6.3 C shim audit

All 6 shims added across Phases 0–3 with replacement paths:

| Shim                        | Reason                               | Future replacement                  |
|-----------------------------+--------------------------------------+-------------------------------------|
| ~grease_set_map_region~     | MKCoordinateRegion struct arg (32 B) | Engine struct-arg dispatch (Phase 10)|
| ~grease_location_latitude~  | CLLocationCoordinate2D struct return | ~ios/call loc :coordinate~ (Phase 10)|
| ~grease_location_longitude~ | CLLocationCoordinate2D struct return | ~ios/call loc :coordinate~ (Phase 10)|
| ~grease_location_accuracy~  | ~horizontalAccuracy~ double getter   | ~objc-rt/msg-send :float64~ direct  |
| ~grease_screen_width~       | CGRect struct return from bounds     | Engine CGRect support (Phase 10)    |
| ~grease_screen_height~      | CGRect struct return from bounds     | Engine CGRect support (Phase 10)    |

All are declared in ~Bridge.h~ and implemented in ~Bridge.m~.

*** 4.6.4 Thread safety audit

- All UIKit calls (tab bar, nav controllers, labels, map view) are wrapped
  in ~on-main~ via single top-level ~on-main~ blocks — not per-call.
- All CLLocationManager lifecycle calls are inside ~on-main~ in
  ~demo-app.location/start!~.
- ~@last-location~ is written by the GPS delegate callback (background thread)
  via ~(reset! last-location loc)~ — safe because atoms are lock-free and
  thread-safe.  ~info/update!~ wraps all UIKit label mutations in ~on-main~.
- ~@app-state~ is written once on the main thread during ~install-tab-bar!~
  and ~install-map-view!~, then read-only.  Thread-safe.
- ~@mgr-state~ is written inside the ~on-main~ block in ~start!~ — safe.

*** 4.6.5 Memory / ARC audit

- ~tab-bar~, ~map-vc~, ~info-vc~, ~map-nav~, ~info-nav~, ~map-view~ — all
  retained in ~@app-state~. ✓
- ~CLLocationManager~ (~mgr-state~) retained in ~@mgr-state~. ✓
- UILabel handles (~lat-lbl~, ~lng-lbl~, ~acc-lbl~) returned from
  ~info/install!~ and stored in ~@app-state~ as ~:info-labels~. ✓
- No ~defclass~ / ObjC delegate registered in the demo — CLLocationManager
  delegate is handled by the ~ios/call setDelegate:~ map pattern (grease
  retains the delegate internally).  No extra atom needed.
- Tab bar items (~make-tab-item!~ return values) passed directly to
  ~setTabBarItem:~ — UIKit retains them; not held by Clojure.  Correct.

* Reference — Encoding Quick-Ref

| ObjC Type           | Encoding | Notes                          |
|---------------------+----------+--------------------------------|
| ~void~              | ~v~      |                                |
| ~id~ / pointer      | ~@~      | Any ObjC object                |
| ~BOOL~              | ~B~      | Clojure ~true~/~false~         |
| ~NSInteger~ (64-bit)| ~q~      |                                |
| ~NSUInteger~        | ~Q~      |                                |
| ~double~ / CGFloat  | ~d~      |                                |
| ~float~             | ~f~      |                                |
| Selector (hidden)   | ~:~      | Always in position 1           |
| self (hidden)       | ~@~      | Always in position 0           |

Full method encoding: ~{ret}@:{arg1}{arg2}...~
Example: ~setRegion:animated:~ (void, struct, BOOL) → handled by C shim.
